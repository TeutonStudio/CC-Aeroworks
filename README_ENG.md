# CC-Aeroworks

CC-Aeroworks is an add-on for Create: Aeroworks that integrates its Control Desks with CC:Tweaked.

This English README is intentionally kept compact for now. The full English documentation will be expanded separately; the current complete project documentation is available in [README_GER.md](README_GER.md).

## Current feature overview

- turns individual Control Desks and connected linear desk networks into programmable CC:Tweaked peripherals;
- adds normal and advanced Computer Control Desks with an embedded computer;
- exposes the embedded-computer APIs `peripherals`, `channels`, `controls`, `wires`, and `telemetry`;
- adds programmable small and large display modules with PPB-based pixel resolution;
- supports touch and draw input on large displays through the combined pointer input mode;
- exposes structured Create Display Link telemetry to Computer Control Desks;
- provides optional Create: Radars compatibility through the isolated radar compatibility module.

For the full current documentation, examples, API details, compatibility notes, and development information, see [README_GER.md](README_GER.md) and the files under [`docs/`](docs/).
