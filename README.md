# CC-Aeroworks

Programmable cockpits for **Create: Aeroworks** and **CC:Tweaked**, built for **Minecraft 1.21.1 / NeoForge**. Connect desks, computers, displays and controls; automate them with Lua, telemetry and optional radar or train integrations.

[Wiki — Deutsch](https://github.com/TeutonStudio/CC-Aeroworks/wiki) · [Wiki — English](https://github.com/TeutonStudio/CC-Aeroworks/wiki/English)

[Download](https://github.com/TeutonStudio/CC-Aeroworks/releases) · [Modrinth](https://modrinth.com/mod/cc-aeroworks) · [Examples](examples/cc/README.md) · [API](docs/cc-peripheral-api.md) · [Issues](https://github.com/TeutonStudio/CC-Aeroworks/issues)

Install the required mods listed in the Wiki on both client and server. Building from source requires Java 21: `./gradlew build`.
